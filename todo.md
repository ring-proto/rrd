Reach-ball GC — DONE (timing caveat RESOLVED via horizon-aligned defaults)** — `engine.compact()` evicts a non-origin slot continuously GC-eligible (`f<floor && vit<φ`) for `cfg.gc_dwell` (default 32 ticks), rebuilding every parallel vector + each `peer.pot` + `dest_slot`; origins never evicted; verified by a middle-eviction compaction-correctness test. **RESOLUTION (landed):** the daemon `Config::default()` is now space-time horizon-aligned (§8) — `D=1, κ=0.01, α=0.1, φ=0.5` ⟹ reach `λ=√(D/κ)=10` equals the vitality horizon `R_V=(1/φ−1)/α=10` (`R_V/λ=1`), with `β=α` (one `age` operator drives both fields).
